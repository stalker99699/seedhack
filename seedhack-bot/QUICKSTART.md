# 🌩️ SeedHack Bot - Быстрый старт

## Установка и запуск за 1 минуту

### 1. Установка зависимостей
```bash
cd seedhack-bot
npm install
```

### 2. Запуск бота
```bash
# Простой запуск с параметрами
OUT1=42000 BOUND1=168000 OUT2=6000 BOUND2=12000 ./run.sh

# Или через npm
OUT1=42000 BOUND1=168000 OUT2=6000 BOUND2=12000 npm start
```

### 3. Подключение к серверу
```bash
# К локальному серверу
MC_HOST=localhost MC_PORT=25565 OUT1=42000 BOUND1=168000 OUT2=6000 BOUND2=12000 ./run.sh

# К удаленному серверу
MC_HOST=play.example.com MC_USERNAME=MyBot OUT1=42000 BOUND1=168000 OUT2=6000 BOUND2=12000 ./run.sh
```

## Как получить параметры для крэкинга?

Вам нужны 4 значения из Minecraft:

1. **OUT1, BOUND1** - результат и граница первого `nextInt()`
2. **OUT2, BOUND2** - результат и граница второго `nextInt()`
3. **CURRENT_TICK** - текущий тик мира (опционально)

### Способ 1: Через мод на сервере
Установите мод типа "Random Observer" который логирует вызовы Random.nextInt()

### Способ 2: Через команду /data
На некоторых серверах доступна команда:
```
/data get entity @p WeatherClearTime
/data get entity @p WeatherRainTime
```

### Способ 3: Наблюдение за погодой
Засеките время смены погоды и используйте его для вычисления bound

## Что дальше?

После запуска бот:
1. ✅ Подключится к серверу
2. 🔓 Восстановит seed мира
3. 🔮 Предскажет погоду
4. 💬 Отправит прогноз в чат

## Команды в чате

- `!weather` - запросить прогноз погоды
- `!help` - справка
