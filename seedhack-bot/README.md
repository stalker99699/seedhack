# 🌩️ SeedHack Bot - Minecraft Weather Prediction Bot

Node.js бот для предсказания погоды в Minecraft через реверс LCG-генератора.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
cd seedhack-bot
npm install
```

### Запуск бота

```bash
# Подключение к локальному серверу
OUT1=42000 BOUND1=168000 OUT2=6000 BOUND2=12000 CURRENT_TICK=78000 PREDICT_TICKS=5 npm start

# Подключение к удаленному серверу
MC_HOST=example.com MC_PORT=25565 MC_USERNAME=MyBot \
  OUT1=42000 BOUND1=168000 OUT2=6000 BOUND2=12000 \
  npm start
```

## ⚙️ Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `MC_HOST` | Адрес сервера | `localhost` |
| `MC_PORT` | Порт сервера | `25565` |
| `MC_USERNAME` | Имя бота | `SeedHackBot` |
| `MC_PASSWORD` | Пароль (для лицензионных аккаунтов) | - |
| `MC_AUTH` | Тип аутентификации (`microsoft` или `mojang`) | `microsoft` |
| `OUT1` | Первое наблюдение nextInt() | - |
| `BOUND1` | Граница первого nextInt() | - |
| `OUT2` | Второе наблюдение nextInt() | - |
| `BOUND2` | Граница второго nextInt() | - |
| `CURRENT_TICK` | Текущий тик мира | - |
| `PREDICT_TICKS` | Количество событий для предсказания | `10` |

## 📖 Команды в чате

- `!weather` - Получить прогноз погоды
- `!help` - Показать справку

## 🔧 Как это работает

1. **Восстановление seed**: Бот использует два наблюдения за `nextInt(bound)` для восстановления внутреннего состояния LCG-генератора Minecraft
2. **Предсказание погоды**: Зная seed, бот симулирует работу генератора и предсказывает следующие события погоды
3. **Интеграция с сервером**: Бот подключается к серверу через mineflayer и отправляет прогнозы в чат

## 🎮 Пример использования

```bash
# 1. Получите данные о погоде с сервера
#    Используйте команду /data или мод для получения:
#    - out1, bound1 - первое наблюдение
#    - out2, bound2 - второе наблюдение
#    - currentTick - текущий тик мира

# 2. Запустите бота
OUT1=42000 BOUND1=168000 OUT2=6000 BOUND2=12000 CURRENT_TICK=78000 npm start

# 3. Бот подключится и отправит прогноз в чат:
#    "Погода: ясно через 15м, дождь через 45м"
```
